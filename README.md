# Thoughtful Velocity

Docusaurus site explaining Thoughtful Velocity: Speed × Clarity × Trust × Reusability.

## Run locally

```bash
npm install
npm start
```

## Build

```bash
npm run build
npm run serve
```

## Before you deploy

Set `url`, `organizationName`, `projectName`, and `editUrl` in `docusaurus.config.js`.

## Content map

- `docs/intro.md` — what the concept is
- `docs/the-problem.md` — why more content isn't the answer
- `docs/formula.md` — the formula and why the factors multiply
- `docs/factors/` — one page per factor
- `docs/diagnose/` — self-assessment with calculator, score interpretation, failure patterns
- `docs/ai.md` — how AI changes each factor
- `docs/related-concepts.md`, `docs/faq.md`, `docs/about.md`
- `src/components/VelocityCalculator.js` — interactive scoring widget
